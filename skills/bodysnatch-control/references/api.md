# BodySnatch Control API v1

API живёт в процессе движка, отдельно от прокси, на случайном порту `127.0.0.1`. Работает и в Electron, и в режиме `npm start`. Клиент автоматически запускает установленную версию 0.1.5+, если API недоступен. Для другого пути используйте --app или BODYSNATCH_APP; --no-start запрещает запуск. POST /api/quit при отсутствии приложения возвращает alreadyStopped:true без запуска. Клиент читает `<профиль>/control-api.json`:

```json
{
  "apiVersion": 1,
  "baseUrl": "http://127.0.0.1:<порт>",
  "token": "<секрет>",
  "pid": 123,
  "version": "..."
}
```

Каждый запрос требует `Authorization: Bearer <token>`. Браузерные Origin / Sec-Fetch-Site отклоняются; CORS не включён. Это локальный доступ того же пользователя, а не сетевой API. Файл создаётся с mode 0600; Windows использует ACL папки профиля пользователя. Администратор и программы того же пользователя не изолированы этим токеном. Запрещено проксировать endpoint наружу без отдельной модели авторизации.

JSON POST: `Content-Type: application/json`, объект, максимум 1 MiB. Ответ `{ok:true,...}` или `{ok:false,error,...}`. Клиент проверяет одновременно HTTP-статус и `ok`. Некоторые старые маршруты установки CA/прокси возвращают `ok:false` при HTTP 200. Некорректные параметры — 400, отсутствие папки/маршрута — 404, конфликт папок — 409, недоступная функция оболочки — 501, необработанная ошибка платформы/диска — 500. Записи выполняются последовательно. GET не является транзакцией относительно всех полей одновременно.

## Состояние и диагностика

| Метод и путь                                     | Назначение                                                                                                                                                                                       |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `GET /api/state`                                 | Снимок: версия, `enabled`, `routeMode: off/system/browser`, конфиг, руты/модули, статистика, CA, системный PAC, upstream, пути. Чтение обновляет проверку системного PAC.                        |
| `GET /api/capabilities`                          | Версия API, маршруты, доступность window/updates/folderPicker.                                                                                                                                   |
| `GET /api/config`                                | Полный сохраняемый конфиг. `port` только для чтения в текущем процессе.                                                                                                                          |
| `GET /api/log?n=200`                             | Последние записи первыми, 0–500. Время `t` — UTC.                                                                                                                                                |
| `POST /api/log/clear`                            | `{}`; очистка журнала во всех подключённых интерфейсах, без сброса счётчиков.                                                                                                                    |
| `GET /api/events`                                | SSE: `state`, `log`, `log-clear`, `files`. `state` означает «перечитай снимок». Поддерживается heartbeat. Клиентский таймаут по умолчанию 300000 мс, для длительного чтения задавай `--timeout`. |
| `GET /api/resolve?url=<URL-encoded HTTP(S) URL>` | Подходящий сайт и результат выбора локального файла: file / missing / passthrough. Показывает соответствие правилам независимо от `enabled`, без запроса на сервер.                              |

## Подмена и настройки

| Метод и путь                           | Тело                                                                                                                                                                                                                                           |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST /api/enabled`                    | `{"enabled":true}` или `false`: общий переключатель подмены и системного PAC. Начальное состояние — off. Внешнее снятие PAC останавливает системный режим; отдельный браузерный режим от него не зависит.                                      |
| `POST /api/proxy/on`, `/api/proxy/off` | `{}`; совместимые команды общего включения/выключения.                                                                                                                                                                                         |
| `POST /api/config`                     | Частичный конфиг напрямую или `{"config":{...}}`. Поля: sites, roots, moduleRoots, servicePrefixes, theme. Массивы и moduleRoots заменяются целиком.                                                                                           |
| `POST /api/site`                       | `{"index":0,"patch":{"mask":{...},"files":[...]}}` или `{"id":"...","patch":{...}}`; обновляет только указанные поля сайта. id имеет приоритет над index.                                                                                      |
| `POST /api/roots`                      | `{"action":"add","path":"F:/code"}`, `{"action":"remove","path":"F:/code"}` или `{"action":"replace","path":"F:/old","replacement":"F:/new"}`. Замена переносит moduleRoots и сохраняет enabled. Удаление снимает выбор модулей из этой папки. |
| `POST /api/module-root`                | `{"module":"Telephony_online","root":"F:/code"}` — выбрать модуль из включённой папки, которая уже есть в roots; `root:null` — снять выбор.                                                                                                    |
| `POST /api/browser/open`               | `{}`; запускает отдельный профиль Chrome/Edge с PAC и SPKI CA, включает подмену. Не меняет системные настройки прокси.                                                                                                                         |

Пример частичного конфига:

```json
{
  "roots": [{ "path": "F:/projects/build/resources", "enabled": true }],
  "moduleRoots": { "Telephony_online": "F:/projects/build/resources" },
  "servicePrefixes": ["static/resources"],
  "theme": "dark"
}
```

Сайт: `{id?,enabled?,useLocal?,mask?,files?,match?,patterns?}`. Маска содержит массивы `prefixes`, `envs`, `hosts`, каждый элемент `{value:string,enabled:boolean,custom?:boolean}`. `files` — такой же массив расширений без точки. Пустой files означает отсутствие фильтра; все элементы enabled:false запрещают все расширения. `patterns`, если задан непустым, имеет приоритет над mask/match. Для маски без префикса используй значение `отсутствует`. `match` принимает строку или массив glob URL. Добавление доменов вне ограничений существующего CA требует явного перевыпуска и повторной установки. `theme` — auto/light/dark; окно получает обновление через события.

## Сертификат и оболочка

| Метод и путь                | Назначение                                                                                                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `GET /api/cert/file`        | Публичный CA в PEM (attachment .crt), без закрытого ключа.                                                                                                               |
| `POST /api/cert/install`    | `{}`; установить CA и проверить доверие. Возможен системный диалог; ответ может содержать manual.                                                                        |
| `POST /api/cert/uninstall`  | `{}`; сначала остановить подмену/PAC, удалить CA из хранилища, оставить файлы CA.                                                                                        |
| `POST /api/cert/reset`      | `{}`; остановить подмену/PAC, удалить CA из хранилища и с диска, выйти. При ошибке удаления доверия ключ сохраняется. Перезапуск отдельной командой пользователя/агента. |
| `GET /api/update`           | Состояние обновлений: idle/available/downloading/ready/error, версия, прогресс, ошибка. Electron.                                                                        |
| `POST /api/update/check`    | `{}`; проверить релиз. Electron.                                                                                                                                         |
| `POST /api/update/download` | `{}`; начать загрузку. Следить через GET update; ответ означает начало, а не завершение. Требуется SHA-256 в метаданных релиза.                                          |
| `POST /api/update/install`  | `{}`; повторная проверка файла, восстановление системного PAC, выход и запуск установщика. Только по запросу пользователя.                                               |
| `POST /api/window`          | `{"action":"show"}`, hide, minimize. Electron.                                                                                                                           |
| `POST /api/open`            | `{"path":"F:/code"}` или `{"root":"F:/code"}`; открыть папку средствами ОС.                                                                                              |
| `POST /api/open-settings`   | `{}`; открыть системные настройки прокси.                                                                                                                                |
| `POST /api/pick-folder`     | `{"title":"..."}`; нативный диалог выбора папки. Для работы без UI задавай абсолютный путь через roots.                                                                  |
| `POST /api/quit`            | `{}`; корректный выход с возвратом системного PAC.                                                                                                                       |

В режиме system PAC опрашивается каждые 3 секунды; время выполнения системной утилиты добавляется к задержке. В режиме off/browser отдельного фонового опроса ОС нет; GET state по-прежнему читает её состояние. `systemProxy.ours` — PAC данного запущенного экземпляра. `systemProxy.overridden` на macOS означает, что VPN/другой механизм перекрывает настроенный PAC. Флаг не доказывает прохождение трафика конкретного браузера: Firefox, VPN, политики, кэш и собственные настройки браузера могут влиять отдельно.
