# BodySnatch Desktop

Подмена JS/CSS сайта локальными файлами **через локальный MITM-прокси**, без расширения
браузера. Работает с любым браузером, который использует системный прокси.

Оболочка — Electron. Настройки те же, что у версии на расширении (odysnatcher/): папки
с кодом, выбранные модули, маска «префикс × окружение × сайт».

## Как это устроено

```
браузер ──► системный прокси 127.0.0.1:8180 (наш)
                ├─ HTTPS: CONNECT → TLS с нашим сертификатом для хоста
                ├─ URL подходит под маску и модуль выбран?
                │     ├─ да: локальный файл есть → отдаём его (200, x-bodysnatch: mirror)
                │     └─ нет: запрос уходит на сервер как обычно (passthrough)
                └─ ответы сайта идут обратно в браузер; CSP снимается
```

- **Подмена детерминирована**: правим байты ответа, поэтому нет ни CSP-конфликтов, ни
  CORS/PNA, ни адблокеров, ни лимитов declarativeNetRequest — всего того, что ломало
  версию на расширении.
- **Сертификат**: корневой CA генерируется в чистом JS (node-forge), листовые сертификаты
  для хостов подписываются им на лету и кэшируются.
- **Системный прокси**: включается/снимается через реестр HKCU + WinINET; снимок прежнего
  состояния возвращается на «Остановить» и при закрытии окна.

## Структура

```
bodysnatch/
  shell/            оболочка Electron: окно, трей, мост к интерфейсу
  proxy/src/
    main.mjs        точка входа: прокси + API + раздача интерфейса
    proxy.mjs       MITM: HTTP, CONNECT+TLS, подмена, проброс, API-хук
    rules.mjs       маски, поиск сайта, разрешение локального файла
    ca.mjs          корневой CA и листовые сертификаты
    certinstall.mjs установка CA в доверенные Windows, проверка, .crt
    sysproxy.mjs    системный прокси Windows: вкл/выкл/снимок/возврат
    api.mjs         /api/state, /api/config, /api/cert/*, /api/proxy/*, /api/log
    scan.mjs        папки и модули для интерфейса
    config.mjs      конфиг (тот же формат, что rules.json у расширения)
  ui/               React + Vite: прокси → сертификат → правила → работа
  scripts/package-electron.mjs  сборка переносимого пакета и .zip
  config/rules.json конфиг по умолчанию
  data/certs/       сюда ложатся rootCA.pem и .crt
  test/             проверки на реальных примерах
```

## Запуск для разработки

```bash
cd bodysnatch
npm install
npm run dev        # Vite 5179 + Electron, DevTools открываются сами
```

Только собранный интерфейс, без Vite: `npm run shell`. Только бэкенд: `npm start`.

DevTools в запущенном приложении — `F12` или `Ctrl+Shift+I`.

## Сборка приложения

```bash
npm run release    # = build:ui + package
```

Готовый пакет: `release/BodySnatch-<версия>-win-x64{,.zip}`. Внутри — Electron-рантайм,
`BodySnatch.exe`, прокси, собранный интерфейс, конфиг и `node-forge`; установка не нужна.

## Включение прокси

1. **Обычный запуск.** Кнопка «Включить прокси» пишет настройки напрямую (reg.exe → PowerShell → HKLM).
2. **Если система запрещает запись**, кнопка называется «Включить прокси (нужно разрешение
   администратора)». Нажатие показывает запрос прав (UAC); привилегированный помощник
   `proxy-elevated.ps1` чинит права на ключ, пишет настройки и включает прокси.
3. **Запуск от администратора** работает тем же путём, только без запроса прав.
4. Если и это не удалось — экран переходит в ручной режим: адрес `127.0.0.1:8180`,
   кнопка «Открыть параметры Windows», «Проверить снова» и «Исправить права и включить».

## Окно приложения

- **Своя шапка** вместо системной: логотип, название, справа две кнопки.
- **«Свернуть»** — окно уходит в панель задач.
- **«Закрыть»** — окно уходит в трей, прокси продолжает работать (двойной клик по значку
  в трее возвращает окно, пункт меню «Остановить и выйти» завершает всё и возвращает
  системный прокси).
- **Размер окна** подстраивается под содержимое: страница сообщает габариты, окно
  подгоняется и не выходит за рабочую область экрана; вручную растянутый размер не
  уменьшается.
- **Иконка** — та же, что у браузерной версии: в окне, трее и как favicon интерфейса.

## Сценарий мастера

1. **Прокси** — показывает системный прокси; «Включить прокси» ставит `127.0.0.1:8180`.
2. **Сертификат** — кнопка установки (Windows спросит подтверждение), «Скачать .crt»,
   команда `certutil` и путь «Продолжить без сертификата».
3. **Правила** — папки с кодом, модули, маска сайта.
4. **Работа** — открывается со **выключенным свитчем** и подсказкой
   «Подмена на паузе. Переключите свитч…»; ниже журнал запросов (`mirror` = локальный файл).
