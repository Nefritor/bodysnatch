# Проверка BodySnatch на Mac через SSH

SSH даёт доступ к терминалу и файлам Mac. API приложения остаётся на loopback Mac: открывать его
в локальную сеть или интернет не требуется. Для проверки графической Electron-версии пользователь
должен войти в macOS; установку доверия сертификату подтверждают на Mac в системном диалоге.

## Включение доступа

1. На Mac: **Системные настройки → Основные → Общий доступ → Удалённый вход / Remote Login**.
2. Включите Remote Login; в списке доступа выберите **«Только эти пользователи»** и нужную учётную запись.
   Полный доступ к диску для этой проверки заранее включать не требуется.
3. В Терминале Mac подготовьте файл ключей:

   ```bash
   mkdir -p ~/.ssh
   chmod 700 ~/.ssh
   touch ~/.ssh/authorized_keys
   chmod 600 ~/.ssh/authorized_keys
   ```

4. Добавьте в `~/.ssh/authorized_keys` **одну строку открытого SSH-ключа** проверяющего агента.
   Ключ начинается с `ssh-ed25519` и предоставляется отдельно. Можно вставить строку так:

   ```bash
   cat >> ~/.ssh/authorized_keys <<'EOF'
   ВСТАВЬТЕ_ПОЛНУЮ_СТРОКУ_ОТКРЫТОГО_КЛЮЧА
   EOF
   ```

   Не заменяйте существующий файл целиком: в нём могут быть другие ключи.
   Пароль пользователя, закрытый ключ и пароль Apple ID передавать не нужно.

## Адрес и проверка сервера

Имя пользователя и локальное имя компьютера:

```bash
whoami
scutil --get LocalHostName
```

IP смотрите в **Системные настройки → Сеть → активное подключение → Подробнее → TCP/IP**.
На странице Remote Login также обычно показывается готовая команда `ssh user@host`.

Отпечаток ключа SSH-сервера:

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

Проверяющему нужны `user@IP`, SSH-порт (обычно 22), отпечаток и информация о том, находятся ли
устройства в одной сети. При первом подключении отпечаток сверяется с полученным с Mac.
Для разных сетей нужен уже настроенный VPN или другой согласованный маршрут. Проброс порта на
роутере и общедоступный SSH для проверки обычно не нужны.

## Что выполняется после подключения

- Чтение версии macOS/архитектуры, `node --version`, `npm --version`, `xcode-select -p`.
- Работа в отдельной папке и отдельном профиле BodySnatch, с сохранением исходных настроек прокси.
- Сборка `.app`/`.dmg`, запуск приложения в пользовательской сессии и проверка локального API.
- Проверка HTTP/HTTPS-подмены, активной сетевой службы, внешнего отключения PAC и возврата настроек.
- Проверка native-установки CA только с подтверждением пользователя в диалоге macOS.

Если Node или инструменты сборки отсутствуют, проверяющий сначала сообщает, что именно требуется.
Не нужно заранее устанавливать неизвестные пакеты или отключать защиту macOS.

Вызов API по SSH после запуска приложения:

```bash
ssh user@mac 'node /путь/к/bodysnatch/skills/bodysnatch-control/scripts/bodysnatch-api.mjs GET /api/state'
```

## Отзыв доступа

Удалите из `~/.ssh/authorized_keys` строку ключа этой проверки (по согласованной метке в конце строки).
Если Remote Login больше не используется, выключите его в тех же настройках. Остальные ключи и
настройки удалять не требуется.

Источник расположения настройки и модели доступа: [Apple — Allow a remote computer to access your Mac](https://support.apple.com/en-ie/guide/mac-help/mchlp1066/27/mac/27).
